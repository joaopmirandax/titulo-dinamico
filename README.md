# Título Dinâmico da Página

Componente React construído para atualizar o título da aba do navegador (`document.title`) em tempo real conforme o usuário digita em um campo de texto.

### O que o projeto faz
- Captura o texto digitado no campo de entrada usando o `useState`.
- Atualiza o `document.title` do navegador automaticamente via `useEffect` a cada alteração do estado.
- Exibe o texto digitado logo abaixo do campo de input para confirmação visual.

### Tecnologias
- React (useState e useEffect)
- JavaScript
- CSS
